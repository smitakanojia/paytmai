Impact & benefits · how we measure

We benchmark against ourselves with the engines switched off.

An ablation, not a strawman

The baseline is the identical agent — same prompts, same tools, same model — with the clock engine and incident engine disabled. We say so on the slide, because a baseline you wrote to lose proves nothing.

The data

300+ labelled cases in English, Hinglish and deliberately messy phrasing · an adversarial set built to induce a wrongful payout · one simulated outage of 500–1,000 cases in 20 minutes, including merchants who never complain.

Two things to say out loud. First, the baseline is an ablation of our own agent, which is the only comparison a technical judge will accept. Second, point at the false-action row: we are reporting a measured number with an interval rather than a zero, and we built an adversarial set specifically to find our own failures.
