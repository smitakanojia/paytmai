Technology · tech stack

Five layers. The expensive part is deterministic.

INTERFACE

React merchant chat, ops console and the live liability ledger over SSE. n8n for WhatsApp and SMS. Sarvam for Hindi speech.

AGENT CORE

Python and FastAPI. A tool-calling loop that plans and writes, with a cost router choosing the tier per case.

CLOCK + INCIDENT

Deadline computation, breach prediction and compensation maths. Clustering on bank × error code × 15-minute window.

POLICY GATE

A YAML rule file encoding RBI TAT, UDIR, the settlement cycle and IOS. Evaluated deterministically. No model in this path.

DATA + TOOLS

SQLite for the prototype. Mocked Paytm APIs mirroring real signatures, so swapping them in is integration, not a rewrite. Append-only audit log.

The cost router — four tiers, cheapest first

Known incident → filled template, zero model calls · Simple case → Claude Haiku 5.5 · Hard or risky → Claude Opus 5.5 · Above caps or fraud-flagged → human, with the deadline on the card. Providers are swappable behind one interface.

Mocked, deliberately

Paytm-side systems are mocked so our week goes into the clock engine, the batching and the eval — the parts that are actually novel.

Keep this slide short out loud. The one line that matters: the policy gate has no model in it. Everything that moves money is deterministic code reading a rule file, and the model only plans and writes prose. That is both the safety story and the cost story. Second point: the mocked tools mirror the real API signatures, so a judge asking "how does this reach production" gets "it is an integration task, not a rewrite."
